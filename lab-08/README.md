# Лабораторна робота №8 — GRASP (варіант 8, логістика)

Java 17, Maven. Відкрити в IntelliJ IDEA: **File → Open → вибрати теку проєкту (або pom.xml) → Open as Project**.
Запуск: клас `logistics.app.Main`.

Документація:
* `docs/ПОЯСНЕННЯ.md` — що, як і чому зроблено (завдання 1–6, метрики);
* `docs/ТЕОРІЯ.md` — теорія та питання для захисту;
* `docs/adr/` — ADR + QOC;
* `docs/cross-review-checklist.md` — чек-лист крос-рев'ю;
* `docs/legacy/` — вихідний «поганий» код.
